# Sabudh Internship Assessments

A continuously maintained collection of my solutions to the **technical assessments and learning exercises** given during my full-time Data Science internship at **Sabudh Foundation**.

This repository is being maintained throughout the internship and will continue to grow as new assessments and learning activities are introduced.

## About

The training covers multiple areas of Data Science, programming, and related technical skills. This repository contains the work I complete as part of that learning process.

The purpose of maintaining it publicly is to create a useful reference for students who may be working on similar problems, while also keeping the solutions open to review and improvement.

The solutions are intended to help with **understanding the problem-solving approach, reasoning, and implementation**, rather than simply providing an answer.

## Purpose

This repository serves two purposes:

* **Learning resource:** Students can refer to the solutions when they are stuck or want to understand another approach to a problem.
* **Open improvement:** Others can review the implementations, identify issues, suggest better approaches, and contribute improvements.

As the internship progresses, more assessments and learning material will be added to the repository.

## Approach

Where applicable, the solutions focus on:

* Understanding the problem before implementing it
* Breaking problems into logical steps
* Writing clear and readable code
* Using appropriate data structures and algorithms
* Writing solutions that work with different inputs
* Considering efficiency and implementation choices
* Understanding the concepts behind an implementation rather than treating it as a black box

The level and approach may vary depending on the requirements of each assessment.

## For Students

If you are working through similar assessments or learning topics, you can use this repository to:

* Understand how a problem can be approached
* Compare your implementation with another solution
* Identify mistakes in your own approach
* Explore alternative ways of solving a problem
* Strengthen programming and problem-solving skills

**Try solving the problem yourself first.** The solutions are most useful as a reference for understanding, debugging, and improving your own implementation.

## Contributions
